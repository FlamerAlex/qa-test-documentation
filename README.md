## Overview

This repository contains selected examples of my QA test documentation created during practical training. It demonstrates test design, functional coverage, negative and boundary testing, and defect reporting.

The materials are based on a training e-commerce application. No real customer data, credentials, or private training access is included.

## Contents

| Folder | Contents |
| --- | --- |
| [`checklists`](checklists) | Checklist for registration, login, logout, and authorization scenarios |
| [`test-cases`](test-cases) | Detailed test cases exported after a privacy review |
| [`bug-reports`](bug-reports) | Sanitized defect reports with reproducible steps and expected/actual results |
| [`evidence`](evidence) | Screenshots only when they contain no personal or confidential information |

## Testing Scope

- Registration and login validation
- Positive, negative, and boundary-value scenarios
- Logout behaviour and authorization state
- Access control for protected pages
- UI and navigation checks

## Tools Used

- Google Sheets / Microsoft Excel — test documentation
- Jira — issue tracking practice
- Google Chrome and DevTools — web testing
- Git and GitHub — version control and portfolio publication

## Note

The raw course files are reviewed and sanitized before being added. Test execution status is reported only for checks that were actually performed.
